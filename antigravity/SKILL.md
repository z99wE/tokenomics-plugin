# Tokenomics for Antigravity

**Small mouth, big brain. Minimum code, maximum impact.**

Tokenomics is inspired by the concepts behind caveman (prose compression)
and ponytail (code minimization), engineered independently as its own Antigravity
skill with token-savings estimation.

## Triggers

Say any of these in Antigravity:
- `tokenomics enable` / `tokenomics disable`
- `caveman-inspired mode` / `ponytail-inspired mode`
- `less tokens` / `minimal code`

## Installation

Copy this `SKILL.md` to `~/.antigravity/skills/tokenomics/`.

Or install via pip:
```bash
pip install tokenomics
```
