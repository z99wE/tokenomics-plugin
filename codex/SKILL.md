# Tokenomics for Codex (OpenAI)

**Small mouth, big brain. Minimum code, maximum impact.**

Tokenomics merges **caveman** (prose compression) + **ponytail** (code minimization) into one Codex skill with token-savings estimation.

## Triggers

Say any of these in Codex:
- `tokenomics enable` / `tokenomics disable`
- `caveman mode` / `ponytail mode`
- `less tokens` / `minimal code`

## Installation

Copy this `SKILL.md` to `~/.agents/skills/tokenomics/` or `~/.codex/skills/tokenomics/`.

Or install via pip:
```bash
pip install tokenomics
```
